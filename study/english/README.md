# 영어 학습 운영 지침

이 폴더는 법원공무원 9급 영어를 제로베이스에서 준비하기 위한 장기 학습 기록이다.

공통 단계 전환은 `../learning-stages.md`를 따른다. 현재 영어는 1단계 `개념 정리`다. 어휘·구문과 독립 독해가 기준을 충족하면 Codex가 자동으로 다음 단계로 전환한다.

1~3단계 문제는 자체 제작이며, 4단계 `실전 기출 문제 20항`은 실제로 출제된 공식 기출을 사용한다. 3단계 자체 제작 20항을 거의 문제없이 푸는 전환 기준을 충족하기 전에는 공식 기출로 올리지 않는다.

## 기본 학습 방식

- 초기에는 `1문제 제시 -> 1응답 -> 즉시 채점과 해설` 방식으로 진행한다.
- 사용자는 문제에 포함된 모든 영어 문장에 자신의 해석을 붙인다.
- 66번부터 사용자는 보기를 참조하지 않고 먼저 독해한 다음 선택지와 대조한다. 평가 시 독립 해석의 정확도와 선택지 정답을 분리한다.
- 정답 선택보다 사용자의 해석 과정에서 독해 실패 원인을 찾는 것을 우선한다.
- 기본 어휘와 구문이 형성되면 여러 문제를 정답 비공개로 푸는 누적 실전형으로 전환한다.
- 마지막 단계에서 실제 법원직 기출과 유사한 길이·구성·시간 제한을 적용한다.

## 문제 유형

- 어휘
- 문법
- 생활영어
- 빈칸 추론
- 문장 배열과 문장 삽입
- 주제·요지·제목
- 세부 내용 일치
- 법률·행정 관련 독해

초기에는 짧은 문장부터 시작하고, 정확도가 높아지면 두세 문장, 짧은 문단, 실제 시험 길이 순으로 늘린다.

## 실전형 문제 출제 품질 규칙

- 영어 58번부터 개념형에서도 선택지에 같은 사건·인물·어휘를 사용하되, 부정·시간 순서·가능성과 실제 발생·주장과 확정 사실을 달리하여 해석 없이 소거하기 어렵게 한다. 정답은 하나로 명확하게 유지한다.

- 실전 기출형 문제에서는 제시문의 핵심 표현과 정답 선택지가 그대로 반복되어 1대1로 매칭되는 문제를 출제하지 않는다.
- 단어의 표면적 일치만으로 정답을 고를 수 있는 저변별 문항을 금지한다.
- 제시문을 해석한 뒤 주제·논리 관계·문법 기능·문맥상 의미를 판단해야 정답을 고를 수 있게 한다.
- 정답 선택지는 제시문의 표현을 적절히 바꾸어 쓰되 의미는 정확히 유지한다.
- 오답 선택지는 문법적으로 어색해서 바로 제거되는 문장만 사용하지 않고, 실제로 혼동할 수 있는 유사 의미·반대 논리·범위 왜곡을 활용한다.
- 실전형 문항은 정답을 알기 위해 최소 두 단계의 판단이 필요하도록 구성한다. 예: 문장 해석 후 글쓴이의 결론 판단, 구문 분석 후 문맥에 맞는 어휘 선택.
- 정답이 제시문과 직접 대응하는 문제는 초기 개념 형성용으로만 제한적으로 사용할 수 있으며, 실전형 점수 평가에는 포함하지 않는다.
- 출제 후 정답 단서가 특정 선택지에만 그대로 복사되었는지, 복수 정답이나 정답 없음 가능성이 있는지 검토한다.

## 해설 절차

사용자가 답과 해석을 제출하면 다음 순서로 분석한다.

1. 정답과 오답을 판정한다.
2. 사용자의 해석에서 주어·동사·목적어·보어를 어떻게 인식했는지 확인한다.
3. 실패 원인을 `단어`, `문법·구문`, `접속·논리`, `지시어`, `선택지 판단`으로 분리한다.
4. 실제 오독을 일으킨 최소 단위만 오답노트에 기록한다.
5. 자연스러운 번역 표현만 다른 경우에는 오답으로 기록하지 않는다.
6. 모든 선택지의 뜻과 오답인 이유를 설명한다.

## 기록 분리 원칙

### 단어 오답

다음 항목은 `vocabulary-active.md`에 기록한다.

- 뜻을 전혀 몰랐다.
- 비슷한 단어와 혼동했다.
- 뜻은 알지만 해당 문맥의 의미를 적용하지 못했다.
- 철자를 잘못 기억했다.
- 정답 판단에 결정적인 단어였다.
- 반복해서 등장했으나 안정적으로 기억하지 못했다.

### 독해·구문 오답

다음 항목은 `reading-errors.md`에 기록한다.

- 주어와 본동사를 찾지 못했다.
- 목적어와 보어를 혼동했다.
- 관계사절·분사구문·전치사구 등 수식 범위를 잘못 잡았다.
- 정형화된 구문을 하나의 의미 단위로 읽지 못했다.
- 접속사의 원인·결과·대조 관계를 놓쳤다.
- 대명사나 지시어가 가리키는 대상을 잘못 찾았다.
- 단어를 모두 개별 번역하여 문장 전체 의미를 반대로 이해했다.

한 문장에서 단어와 구문을 모두 틀렸다면 두 문서에 분리하여 기록한다.

## 최소 단위 기록 원칙

- 원문 전체를 독해 오답노트에 복사하지 않는다.
- 실패를 일으킨 단어나 구조만 기록한다.
- 예: `consider + A + adjective = A를 ~하다고 여기다`
- 예: `be reluctant to do = ~하기를 꺼리다`
- 예: `although A, B = A이기는 하지만 B이다`
- 필요한 경우에만 짧은 자체 제작 예문을 한 개 덧붙인다.

## 재시험 원칙

- 최초 문장을 그대로 다시 내지 않는다.
- 같은 단어·구문·논리 관계를 새로운 문장에 넣어 확인한다.
- 초기 재시험 문장에는 핵심 복습 항목을 한두 개만 넣는다.
- 이후에는 이미 배운 단어와 구문을 두세 개 결합한 문장으로 확장한다.
- 같은 문장을 외워 맞힌 것은 숙달 근거로 인정하지 않는다.

예시:

- 최초 구조: `The judge considered the testimony credible.`
- 변형 확인: `The committee considered the proposal impractical.`

## 단어 시험 방식

단어는 다음 세 방식으로 확인한다.

1. 영어 단어를 보고 핵심 뜻 말하기
2. 한국어 뜻을 보고 영어 철자 쓰기
3. 새로운 문맥의 빈칸이나 문장에서 의미 적용하기

법원직은 객관식 시험이므로 뜻과 문맥 인식을 주력으로 하고 철자 회상은 보조 수단으로 사용한다.

### 50문제 단위 오답 단어 시험

- 영어 본문 문제 50번, 100번, 150번처럼 50문제마다 활성 오답 단어 시험을 실시한다.
- 시험지는 범용 텍스트 파일 `wrong-words-test.txt`에 영어 표제어만 기록한다.
- 사용자는 파일의 영어 단어를 보고 한국어 핵심 뜻을 답한다.
- 시험 전에는 같은 파일에 한국어 정답이나 해설을 기록하지 않는다.
- 시험 시점의 `vocabulary-active.md` 항목을 기준으로 시험지를 갱신한다.
- 채점 결과는 `vocabulary-active.md`의 확인 이력과 `session-log.md`에 반영한다.

## 복습 간격과 숙달

- 최초 등록 다음 날
- 3일 후
- 7일 후
- 14일 후
- 30일 후

운영 원칙:

- 같은 세션의 즉시 정답은 숙달 근거로 계산하지 않는다.
- 틀린 항목은 기록을 삭제하지 않고 다음 날부터 다시 확인한다.
- 단어는 뜻·철자·새 문맥 적용을 모두 확인해야 한다.
- 구문은 서로 다른 새 문장에서 최소 3회 정확히 해석해야 한다.
- 14일 및 30일 확인을 포함해 안정적으로 성공하면 `mastered.md`로 이동한다.
- 숙달 후 다시 틀리면 기존 이력을 보존한 채 활성 문서에 재등록한다.

## 테스트 문서 운영

- `review-test.md`에는 현재 복습일이 된 항목만 문제 형태로 배치한다.
- 답은 사용자가 응답하기 전까지 공개하지 않는다.
- 테스트가 끝나면 결과를 활성 오답노트의 확인 이력과 `session-log.md`에 반영한다.
- 완료된 시험지는 결과 반영 후 다음 복습 세트로 교체할 수 있다.

## 기록하지 않는 경우

- 의미는 정확하고 한국어 표현만 자연스럽지 않은 경우
- 어순이 직역투이지만 문장의 논리와 결론을 정확히 이해한 경우
- 정답에 영향을 주지 않은 사소한 표현 차이
- 여러 차례 안정적으로 이해한 기본 단어

## 실전형 전환 기준

- 짧은 문장의 주어와 본동사를 안정적으로 찾는다.
- 기본 구문을 새로운 문장에서도 적용한다.
- 짧은 문단에서 대조·원인·결과를 구분한다.
- 초기 어휘·구문 문제에서 이유를 설명하며 일정한 정답률을 유지한다.

위 조건이 형성되면 5문제, 10문제, 20문제 묶음 순으로 정답 비공개 실전형을 확대한다.

## 세션 종료 시 갱신

1. `current-state.md`: 진행 범위, 독해 수준, 강점, 주요 병목
2. `vocabulary-active.md`: 새 단어와 분산 확인 결과
3. `reading-errors.md`: 새 구문·논리 오류와 분산 확인 결과
4. `review-test.md`: 다음 복습 대상
5. `session-log.md`: 날짜, 문제 수, 변화와 다음 단계
6. 숙달 조건 충족 시 `mastered.md`

## 학습 중 문서 갱신 주기

- 채점과 해설은 매 문제 응답 직후 제공한다.
- 활성 오답노트·현재 상태·세션 기록의 파일 반영은 기본적으로 5문제마다 묶어서 한다.
- 갱신 대기 중인 단어·구문·오독은 대화 내에서 유지한 뒤 다음 묶음 갱신 때 한꺼번에 반영한다.
- 사용자가 세션 종료나 과목 전환을 요청하면 5문제를 채우지 않았더라도 대기 중인 내용을 즉시 반영한다.
- 중요한 운영 규칙 변경이나 기록 유실 위험이 있는 경우에는 5문제 전에도 즉시 반영할 수 있다.
