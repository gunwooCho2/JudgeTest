# 영어 학습 세션 기록

## 2026-08-21 학습 체계 확정

- 정식 영어 학습은 아직 시작하지 않음.
- 초기에는 한 문제씩 제시하고 사용자가 모든 영어 문장을 직접 해석함.
- 해석 실패 원인을 단어와 독해·구문으로 분리함.
- 원문 전체가 아니라 실패를 일으킨 최소 단위만 기록함.
- 복습에서는 같은 단어와 구문을 새로운 문장에 넣어 확인함.
- 단어 시험은 의미·철자·새 문맥 적용으로 구성함.
- 맛보기 5문제와 `credible`은 정식 학습 기록에서 제외함.
- 실전 기출형에서는 제시문과 정답 선택지가 표면적으로 1대1 매칭되는 저변별 문항을 금지함.
- 실전형 문항은 해석 후 논리·문법·문맥을 추가로 판단하는 최소 두 단계 구조로 출제함.
