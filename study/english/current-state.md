# 영어 현재 학습 상태

마지막 갱신: 2026-08-21, 학습 체계만 확정, 정식 학습 시작 전

## 목표

- 장기 목표: 법원공무원 9급 영어 대비
- 현재 단계: 제로베이스 진단 전
- 학습 방식: 문제 선행, 사용자 전 문장 해석, 즉시 원인 분석

## 현재 확인된 상태

- 사용자는 자신의 영어 독해 능력이 상당히 낮다고 평가한다.
- 맛보기 어휘 문제에서 `credible`의 뜻을 몰라 무응답했다.
- 맛보기 문제는 정식 진단 및 오답 기록에 포함하지 않는다.
- 단어 부족과 문장 구조 이해 부족 중 어느 쪽이 주된 병목인지는 아직 확인되지 않았다.

## 초기 운영

- 짧은 문장부터 한 문제씩 진행한다.
- 사용자는 모든 영어 문장에 자신의 해석을 붙인다.
- 단어와 구문 실패를 분리해 기록한다.
- 원문 전체가 아니라 실패를 일으킨 최소 단위를 저장한다.
- 재시험은 반드시 새로운 문장으로 한다.

## 다음 시작점

1. 짧은 어휘·구문 혼합 문제
2. 사용자의 문장별 해석 확인
3. 주어·본동사 식별 능력 진단
4. 최초 활성 단어와 구문 등록
