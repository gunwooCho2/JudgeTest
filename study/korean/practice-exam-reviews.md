# 국어 연습 기출 묶음 검토

확립: 2026-08-27. 각 3단계 묶음의 학습자 취약점, 출제물 취약점, 대표 예, 보완점, 승급 평가 유효 여부를 기록한다.

## 시범 묶음 - 구 146~165번

### 판정

- 결과: 20/20.
- 승급 평가: **무효**.
- 이유: 실제 2025·2026 법원직 국어보다 지문량, 정보·개념 밀도, 선택지 경쟁도, 세부 유형, 시간 부담이 낮았다.
- 학습자 취약점: 판정 불가. 문항이 충분히 변별하지 못했다.

### 대표적인 출제물 취약점

| 구분 | 대표 예 | 취약점 |
|---|---|---|
| 선택지 경쟁도 | 161번의 ‘품사가 같다’ | 정의와 즉시 충돌해 세밀한 비교가 필요 없었다. |
| 단순 규칙 | 162번 맞춤법 | 복수 규칙과 문맥 적용이 부족했다. |
| 중의성 | 163번에서 ‘어제’만 추가 | 중의성이 남는 사실이 너무 명백했다. |
| 문학 오답 | 164번의 ‘격렬한 갈등’ | 작품에 근거가 없는 과장이라 쉽게 제거됐다. |
| 시어 기능 | 165번의 ‘분노’, ‘문명 비판’ | 선택지들이 같은 해석 축에서 경쟁하지 않았다. |
| 지문 부담 | 상변화 물질·공정성 지문 | 핵심 정의가 짧고 선택지가 거의 그대로 반복했다. |
| 문학 구성 | 짧은 자체 시·산문 | 장문, 작품 비교, 외적 준거를 재현하지 못했다. |
| 문법 구성 | 품사·맞춤법·중의성 중심 | 중세 국어와 복합 음운 변동이 빠졌다. |
| 시험 조건 | 한 문제씩 제시 | 긴 지문 유지와 실제 시간 배분 부담이 없었다. |

### 확인 가능한 강점

- 짧은 지문의 명시 정보, 기본 자료 계산, 기본 문법·맞춤법을 실수 없이 처리했다.
- 이는 기초 정확도의 근거일 뿐 실제 기출 100점 수준의 근거는 아니다.

### 보완점

1. 새 3단계는 `1회 연습 기출 문제` 1번부터 다시 시작한다.
2. 최근 실제 시험지를 기준으로 장문 공유 지문과 세부 유형을 비례 배치한다.
3. 현대·고전 산문, 복합 시, 외적 준거, 중세 국어, 음운, 긴 비문학 관점·사례 적용을 포함한다.
4. 오답은 정답과 같은 어휘·판단 축을 공유하고 범위·조건·주체·시점·인과 일부만 바꾼다.
5. 각 오답이 왜 매력적인지 설명할 수 없는 보기는 교체한다.
6. 회차 종료 후 학습자 오답뿐 아니라 문항 변별력과 출제 실패도 검토한다.

## 1회 연습 기출 문제

### 운영 변경

- 사용자가 제공한 2024·2025·2026 법원 9급 국어 공식 문제지를 직접 확인했다.
- 실제 최근 시험은 국어 25문항이므로 3단계 회차도 `1~25번` 체계로 변경했다.
- 2026은 현대소설 장문 1~4번과 장문 비문학 19~22번 등 한 지문에 여러 문항을 연결하는 구성이 확인되었고, 2025에는 중세 국어와 고전소설 묶음이 포함되어 있었다.

### 결과

- 완료: 2026-08-28.
- 결과: **23/25 (92%)**.
- 정답: 1~5, 7~12, 14~25번.
- 오답: **6번, 13번**.
- 14번은 사용자가 ③의 설명이 어색하다고 지적했다. 정답 ④의 단일성에는 영향이 없었으나, ③의 `-도록`을 단순히 조건·상황으로 설명한 문구는 정확도가 낮아 출제 품질 보완 대상으로 기록한다.

### 학습자 취약점

1. **평가 기준을 여러 축으로 유지하는 문제 — 6번**
   - 사용자 답 ③, 정답 ④.
   - 특정 집단에 불리한 결과가 반복된다는 사실은 결과 편향을 의심하게 하지만, 그것만으로 평가 목적과의 관련성 및 보완 장치 검토를 생략할 수는 없다.
   - 한 판단 축에서 문제가 확인되었을 때 다른 판단 축까지 불필요하다고 넘겨 버리지 않도록 보완할 필요가 있다.

2. **파생어와 활용형 구분 — 13번**
   - 사용자 답 ①, 정답 ③.
   - `군침`은 접두사 `군-`과 어근 `침`이 결합한 파생어이고, `먹었다`는 어근 `먹-`에 어미가 결합한 활용형이므로 파생어가 아니다.
   - 기존 K15(파생어와 용언 활용)의 취약점이 다시 확인되었다.

### 확인된 강점

- 장문 현대소설 1~4번 전부 정답: 서술 방식, 세부 내용, 지시 부분의 기능, 외적 준거 적용을 안정적으로 처리했다.
- 중세 국어 8번, 음운 12번, 안은문장 14번, 높임 15번, 맞춤법 17번, 보조 용언 18번을 정답 처리했다.
- 긴 비문학 묶음 19~22번 전부 정답: 중심 논지, 사례 적용, 자료 해석, 인과 추론을 일관되게 구분했다.
- 조건·함의와 자료 판단 16·23·24번도 정답으로, 필요조건과 과잉 일반화 구분은 이번 회차에서 안정적이었다.

### 출제물 난이도 검수

- 승급 평가: **무효**.
- 이유: 23/25의 높은 정답률과 별개로, 실제 2024~2026 법원직 국어와 비교하면 이번 1회차는 여전히 난도가 부족했다.
- 실제 기출의 25문항 체계와 장문 공유 지문 형식은 일부 반영했으나 다음 차이가 남았다.
  - 현대시·고전시가 및 복합 작품 비교가 빠졌다.
  - 고전소설 문항이 현대어 자체 지문으로 제작되어 실제 고전 문장의 독해 부담을 재현하지 못했다.
  - 중세 국어가 1문항에 그쳐 국어사·고전 문법의 적용 깊이가 부족했다.
  - 5~7번, 16번, 23~24번 등 일부 문항은 공식 기출보다 지문·선지가 짧고 오답 소거가 쉬웠다.
  - 19~22번 비문학은 공유 지문 구조는 맞췄지만 실제 기출보다 개념 밀도와 선택지 간 경합도가 낮았다.
- 따라서 이 회차의 92%는 **3단계 → 4단계 승급을 위한 고득점 회차로 계산하지 않는다. 유효 고득점 회차는 계속 0회다.**

### 다음 회차 보완점

1. 실제 2024~2026 기출의 영역 비중을 다시 대조하여 현대시·고전시가/고전산문·현대산문·비문학·문법·국어사를 균형 있게 배치한다.
2. 장문 지문은 단순 내용 확인이 아니라 관점 비교, 외적 준거 적용, 표현 기능, 세부 추론을 3~4문항에 연결한다.
3. 고전 문학은 현대어로만 재작성하지 않고 실제 고전 문체와 어휘 해독 부담에 준하는 자체 지문을 제작한다.
4. 문법은 단순 정의 확인보다 <보기> 규칙을 새 사례에 적용하는 유형을 늘린다.
5. 6번 취약점과 관련해 복수 평가 기준을 동시에 유지해야 하는 사례 문제를 다시 넣는다.
6. 13번 취약점과 관련해 파생 접미사·전성 어미·일반 어미를 교차 판별하는 문항을 포함한다.
7. 오답 선택지는 정답과 같은 판단 축을 공유하도록 만들어 한 단어만 보고 쉽게 소거되지 않게 한다.

### 진행 상태

- 현재 단계: 3단계 `연습 기출 문제 25항`.
- 1회차: 23/25, 난이도 검수 실패로 승급 평가 제외.
- 유효 고득점 회차: **0회**.
- 다음 시작 위치: `2회 연습 기출 문제` 1번.
