# 국어 학습 운영 지침

확립: 2026-08-26. 목표는 법원공무원 9급 국어 대비이며, 자체 제작 문제는 명백한 사실 판별이 가능한 영역 중심으로 운영한다.

공통 단계 전환은 `../learning-stages.md`를 따르되, 국어는 2026-08-28 합의에 따라 자체 제작 문제의 역할을 제한한다. 공식 고난도 독해·문학 해석은 자체 생성으로 충분히 재현하기 어렵다고 확인되었으므로, 해당 능력의 평가와 숙달은 공식 기출·검증 자료를 우선한다.

## 최신 사용자 합의

- 한 번에 한 문제를 제시하고 응답 후 채점한다.
- 1~2단계는 학습용 자체 제작 문제다.
- 국어 자체 제작 문제는 **문장 성분, 품사, 형태론, 음운, 맞춤법, 표준어, 띄어쓰기, 높임법, 문장 구조, 중세 국어 등 정답 근거가 명백한 사실·규칙 영역**을 중심으로 출제한다.
- 자체 제작으로 공식 고난도 독해·문학 해석 능력을 숙달시키려 하지 않는다. 비문학 독해, 문학 작품 해석, 외적 준거 적용처럼 선지 간 미세한 의미·논리 경계가 핵심인 영역은 공식 기출·검증 자료를 우선 사용한다.
- 자체 제작 문제의 난도를 높일 때는 애매한 해석을 만들지 말고, 여러 문법 규칙·개념을 교차 적용하거나 유사 개념을 정확히 구별하도록 한다.
- 4단계의 공식 기출 사용은 유지한다. 자체 제작 성적만으로 독해·문학까지 공식 기출 수준에 도달했다고 추론하지 않는다.
- 63번 답변 이후에는 **번호만 답해도 된다. 풀이 근거를 매번 요구하지 않는다.** 사용자는 문제를 많이 접하고, 궁금한 점만 별도로 질문하기를 원한다.
- 2단계에서는 정답이면 짧게 정답과 핵심을 확인하고 다음 문제를 내며, 오답이면 선택한 보기의 오류와 정답 근거를 간결하게 설명한다.
- 과거의 '모든 보기 상세 해설'보다 위 최신 국어 요청을 우선한다. 상세 질문을 받으면 충분히 설명한다.
- 틀릴 가능성이 높은 취약 유형과 미학습 영역을 우선하되, 직전 해설을 그대로 재현하는 쉬운 문제를 연달아 내지 않는다.
- 근거 없이 번호만 답했다고 '찍음'으로 기록하지 않는다. 사용자가 직관적으로 아는 맞춤법과 온전히 추측한 답도 구분한다.

## 자체 제작 문제 허용 범위

우선 출제 영역:

- 품사 판별 및 품사 간 구별
- 문장 성분
- 단어 형성: 단일어·합성어·파생어, 어근·접사, 활용형과 파생어 구별
- 조사·어미·의존 명사 등 형태·기능 구별
- 문장의 짜임과 안은문장·이어진문장
- 높임법, 시제·상, 피동·사동 등 문법 범주
- 음운 체계와 음운 변동
- 맞춤법, 표준어, 표준 발음, 띄어쓰기
- 어휘의 규범적 용법 및 명백한 의미 구별
- 중세 국어·국어사에서 규칙과 자료로 정오가 명확히 결정되는 내용

자체 제작에서 원칙적으로 제외하거나 보조 훈련에만 사용하는 영역:

- 장문 비문학의 고난도 추론·평가
- 현대시·고전시가의 미세한 해석 경쟁
- 소설에서 심리·서술 기능을 미세하게 가르는 고난도 선지
- 외적 준거를 적용해 여러 해석 중 가장 적절한 것을 고르는 유형
- 지문이 규정하지 않은 개념 경계를 이용해야 정답이 결정되는 문제

위 제외 영역은 실제 법원직 국어 대비에서 중요하지 않다는 뜻이 아니다. **자체 생성 문제 대신 공식 기출·검증된 문제로 훈련한다는 의미**다.

## 자체 문제 검수

- 정답은 국어 규범·문법 체계 또는 제시된 명시적 조건으로 객관적으로 확정되어야 한다.
- 복수 해석이 가능한 예문을 피한다.
- 오답은 단순히 이상한 문장으로 만들지 않고 실제로 혼동하기 쉬운 인접 개념을 사용한다.
- 한 선지만 `항상·반드시·전혀·오직` 등의 표현 때문에 쉽게 튀지 않게 한다.
- 선택지 문체보다 해당 개념의 정확한 지식이 정답을 결정하게 한다.
- 출제 전에 각 선지의 품사·문장 성분·형태 분석 단위를 명시적으로 다시 확인한다.
- 불확실한 규범 사항은 국립국어원 등 공식 자료를 확인한다.

## 기록과 평가

- `current-state.md`: 마지막 채점/미응답 번호, 강점, 취약점, 다음 방향.
- `error-notes.md`: 오답과 중요한 설명 보정, 확인 이력·도움 수준·다음 확인일.
- `session-log.md`: 문항별 결과와 운영 변경. 원문이 보존되지 않은 초기 문항은 요약으로 표시하며 원문을 지어내지 않는다.
- `practice-exam-reviews.md`: 과거 자체 실전 묶음의 결과와 출제 한계 이력을 보존한다.
- 과거 1·2회 자체 연습 기출의 높은 점수는 공식 독해·문학 수준의 근거로 사용하지 않는다.
- 기록 때문에 매 문제 지연시키지 않는다. 저장 주기는 실행 환경에 따라 다음과 같이 적용하며, 종료·전환 시에는 주기를 채우지 못한 미반영분도 모두 저장한다.
  - **Codex 환경:** 일반적으로 로컬 저장소를 사용하고 최신 상태 조회 및 원격 저장에만 GitHub를 이용하면 10문항 단위로 저장한다.
  - **Chat Web 환경:** 최신 상태 조회·문항 기록·저장을 모두 GitHub로 처리하면 20문항 단위로 저장한다.
- 같은 날 반복 정답은 숙달 판정으로 쓰지 않는다. 저장소의 2일/7일/14일 이상 분산 확인 및 추가 혼합 확인 규칙을 따른다.
- 번호만 답한 정답은 선택 정답으로 기록하되 설명을 통한 독립 숙달 확인으로 계산하지 않는다. 장기 숙달 확인이 필요하면 별도 확인임을 알리고 짧게 근거를 요청한다.
- 오답 노트 삭제 대신 숙달 근거를 남기고 보관한다. 현재 국어에서 장기 숙달로 제거할 항목은 없다.
- 출제 오류는 사용자 오답으로 계산하지 않는다.
- Git 커밋/푸시는 별도 요청 없이 하지 않는다.
