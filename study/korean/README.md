# 국어 학습 운영 지침

확립: 2026-08-26. 목표는 법원공무원 9급 국어 대비이며, 현재는 개념 형성에서 자체 실전형 연습으로 전환한 단계다.

공통 단계 전환은 `../learning-stages.md`를 따른다. 현재 국어는 3단계 `연습 기출 문제 20항`이다. 자체 제작 20문항을 중간 채점·해설 없이 풀고, 묶음 종료 후 한꺼번에 채점한다.

## 최신 사용자 합의

- 한 번에 한 문제를 제시하고 응답 후 채점한다.
- 1~3단계의 `연습 기출`은 공식 기출의 유형·난도를 참고한 자체 제작 문제다. 4단계 `실전 기출 문제 20항`은 실제로 출제된 공식 기출 문제를 사용한다.
- 4단계는 자체 제작 연습 20항에서 2회 연속 18/20 이상 등 `../learning-stages.md`의 기준을 충족한 뒤 자동 전환한다.
- 63번 답변 이후에는 **번호만 답해도 된다. 풀이 근거를 매번 요구하지 않는다.** 사용자는 문제를 많이 접하고, 궁금한 점만 별도로 질문하기를 원한다.
- 2단계에서는 정답이면 짧게 정답과 핵심을 확인하고 다음 문제를 내며, 오답이면 선택한 보기의 오류와 정답 근거를 간결하게 설명한다. 3단계에서는 20문항이 끝날 때까지 정답·오답과 해설을 공개하지 않고, 완료 후 한꺼번에 채점·분석한다.
- 과거의 '모든 보기 상세 해설'보다 위 최신 국어 요청을 우선한다. 상세 질문을 받으면 충분히 설명한다.
- 틀릴 가능성이 높은 취약 유형과 미학습 영역을 우선하되, 직전 해설을 그대로 재현하는 쉬운 문제를 연달아 내지 않는다.
- 지문·보기의 단순 단어 매칭으로 풀리는 변별력 낮은 문항은 피한다. 선택지는 주제·어휘를 공유하되 범위, 조건, 논리, 시점 등이 달라야 한다.
- 문제마다 '자체 제작'임을 명확히 한다. 현재까지 실제 법원직 기출 수준과의 동등성이나 합격 점수를 검증한 것은 아니다.
- 근거 없이 번호만 답했다고 '찍음'으로 기록하지 않는다. 사용자가 직관적으로 아는 맞춤법과 온전히 추측한 답도 구분한다.

## 기록과 평가

- `current-state.md`: 마지막 채점/미응답 번호, 강점, 취약점, 다음 방향.
- `error-notes.md`: 오답과 중요한 설명 보정, 확인 이력·도움 수준·다음 확인일.
- `session-log.md`: 문항별 결과와 운영 변경. 원문이 보존되지 않은 초기 문항은 요약으로 표시하며 원문을 지어내지 않는다.
- 기록 때문에 매 문제 지연시키지 않는다. 저장 주기는 실행 환경에 따라 다음과 같이 적용하며, 종료·전환 시에는 주기를 채우지 못한 미반영분도 모두 저장한다.
  - **Codex 환경:** 일반적으로 로컬 저장소를 사용하고 최신 상태 조회 및 원격 저장에만 GitHub를 이용하면 10문항 단위로 저장한다.
  - **Chat Web 환경:** 최신 상태 조회·문항 기록·저장을 모두 GitHub로 처리하면 20문항 단위로 저장한다.
- 같은 날 반복 정답은 숙달 판정으로 쓰지 않는다. 저장소의 2일/7일/14일 이상 분산 확인 및 추가 혼합 확인 규칙을 따른다.
- 번호만 답한 정답은 선택 정답으로 기록하되 설명을 통한 독립 숙달 확인으로 계산하지 않는다. 장기 숙달 확인이 필요하면 별도 확인임을 알리고 짧게 근거를 요청한다.
- 오답 노트 삭제 대신 숙달 근거를 남기고 보관한다. 현재 국어에서 장기 숙달로 제거할 항목은 없다.
- 출제 오류는 사용자 오답으로 계산하지 않는다. 용언/절/문장 성분의 분석 단위를 명확히 하고, 복수 해석이 가능한 예문을 피한다.
- 당일 설명과 검색으로 품사 변경 등을 확인한 경우에도 이후 새 출제에서 불확실하면 국립국어원 등 공식 자료를 확인한다.
- Git 커밋/푸시는 별도 요청 없이 하지 않는다.
